# Android Sender Program

This is the code source for the Android Sender Program. It takes in a string of text and then outputs a pattern of vibrations in binary.

## AI Policy

Please do not use Generative AI coding tools on this repo. The supposed speed benefits of AI coding are counteracted by the time it takes for [humans (your other team members) to review the code](https://fion.ac/jellyfish.pdf).
